\section{Nachweis eines Reportergenproduktes in transgenen Pflanzen}\label{sec:nachweis-eines-reportergenproduktes-in-transgenen-pflanzen}

\subsection{Einführung}\label{subsec:einfuhrung}

\defin{genexpressionsanalyse}

\ausschnitt{Die Genexpressionsanalyse kann sowohl für einzelne Transkripte als auch für das ganze
Transkriptom angewendet werden und ermöglicht qualitative und
quantitative Aussagen über die Aktivität der Gene.

Im Kandidatengenansatz muss nur die Sequenzinformation des zu
untersuchenden Transkripts bekannt sein.

Für die Transkriptom-Analyse wird die gesamte Sequenzinformation des
Transkriptoms gebraucht (oder gleichzeitig generiert).}{folien21}

\defin{reportergen}

Reportergenprodukte müssen möglichst einfach nachweisbar sein und nicht toxisch für den Organismus oder die Zellen,
in denen sie gebildet werden. \cite{folien21}

Ein Reportergen gibt Auskunft über: \cite{folien21}
\begin{itemize}
    \item Aktivität von Promotoren
    \begin{itemize}
        \item Wann und wo ist ein Gen
        exprimiert?
        \item Welche Region eines Promotors hat
        welche Funktion?
        \item Aufbau: ``Promotor::ReporterORF''
    \end{itemize}
    \item Lokalisation von Proteinen
    \begin{itemize}
        \item Wo in der Zelle ist ein Protein
        lokalisiert?
        \item Welche Region eines Proteins hat
        welche Funktion?
        \item Aufbau: ``ProteinORF:ReporterORF''
    \end{itemize}
\end{itemize}

\paragraph{Anforderungen an ein Reporterprotein} sind: \cite{folien21}

\begin{itemize}
    \item hohe Sensitivität
    \item geringe endogene Aktivität (kein/wenig Hintergrundsignal)
    \item möglichst weiter (linearer) Messbereich
    \item qualitative und quantitative Nachweisbarkeit
    \item hohe Zuverlässigkeit und Reproduzierbarkeit
    \item leichte Durchführbarkeit (geringer apparativer Aufwand)
    \item möglichst nicht-invasive Detektion, idealerweise auch am lebenden Objekt
    \item je nach Anwendung: hohe oder geringe Stabilität
    \item weitere, jeweils experimentspezifische Anforderungen
\end{itemize}


\defin{gus}

\begin{itemize}
    \item Enzym aus \textit{E.~coli} K12 (\textit{uidA}-Gen)
    \item (fast) keine Hintergrundaktivität in Pflanzen
    \item benötigt keine Co-Faktoren oder Metalle
    \item aktiv über einen weiten pH-Bereich
    \item (temperatur-)stabil bis 55\,°C, bei 4\,°C und bei $-70\,°$C
    \item viele Nachweismethoden (substratabhängig)
    \begin{itemize}
        \item colorimetrisch
        \item fluorimetrisch
        \item histochemisch
    \end{itemize}
    \item quantifizierbar
    \item sehr sensitiv (Verstärkung der Sensitivität durch die katalytische Substratumsetzung)
\end{itemize}
