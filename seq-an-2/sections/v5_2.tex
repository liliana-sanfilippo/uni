\section{Introduction}\label{sec:introduction}
\skript{RNA is in many ways similar to DNA, with a few important differences:
\begin{itemize}
    \item Thymine (T) is replaced by uracil (U), so the RNA alphabet is
    $\Sigma_{\mathrm{RNA}} = \{\mathtt{A}, \mathtt{C}, \mathtt{G}, \mathtt{U}\}$.
    \item The additional base pair $\{\mathtt{G}, \mathtt{U}\}$ can be formed.
    \item RNA is less stable than DNA and more easily degraded.
    \item RNA mostly occurs as a single-stranded molecule that forms secondary structures by base pairing.
    \item While DNA is mainly the carrier of genetic information, RNA has a wide variety of tasks in the
    cell, e.g.
    \begin{itemize}
        \item it acts as messenger (mRNA), transporting the transcribed genetic information,
        \item it has regulatory functions,
        \item it has structural tasks, e.g.\ in forming a part of the ribosome (rRNA),
        \item it takes an active role in cellular processes, e.g.\ in the translation of mRNA to proteins,
        by transferring amino acids (tRNA).
    \end{itemize}
\end{itemize}

As with proteins, the three-dimensional structure of an RNA molecule is crucial in determining its
function. Since 3D-structure is hard to determine, an intermediate structural level, the
\emph{secondary structure}, is frequently considered. The secondary structure of an RNA molecule
simply determines the intra-molecular basepairs. As with DNA, the Watson-Crick pairs
$\{\mathtt{A}, \mathtt{U}\}$ and $\{\mathtt{C}, \mathtt{G}\}$ stabilize the molecule, but also the
``wobble pair'' $\{\mathtt{G}, \mathtt{U}\}$ adds structural stability. We now define this formally.

Let $s\in\{\mathtt{A}, \mathtt{C}, \mathtt{G}, \mathtt{U}\}^n$ be an RNA sequence of length $n$.}

\section{The Optimization Problem}\label{sec:the-optimization-problem}

\skript{Over time, an RNA molecule may assume several distinct structures. The more energetically stable a
structure is, the more likely the molecule will assume this structure. To make this precise, we need
to define an energy model for all secondary structure elements. This can become quite complicated
(the problem of predicting RNA structures could fill an entire course), so here we only consider a
drastically simplified version of the problem: We assign a score (that can be interpreted as
``stability'' measure or negative free energy) to each basepair, depending on its type. We can simply
count basepairs by assigning $+1$ to each pair, or we may take their relative stability into account
by assigning $\mathrm{score}(\{\mathtt{A},\mathtt{U}\}) := 2$,
$\mathrm{score}(\{\mathtt{C},\mathtt{G}\}) := 3$, $\mathrm{score}(\{\mathtt{G},\mathtt{U}\}) := 1$, for
example. On a sequence $s$ of length $n$, the score of a basepair $b = \{i,j\}$ is then defined as
$\mathrm{score}(b) := \mathrm{score}(\{s[i], s[j]\})$.}

\section{Context-Free Grammars}\label{sec:context-free-grammars}

\skript{From the above discussion of the dot-bracket notation, we may say that a (simple secondary) structure
is
\begin{enumerate}\setcounter{enumi}{-1}
\item either the empty structure,
\item or an unpaired base, followed by a structure,
\item or a structure, followed by an unpaired base,
\item or an outer basepair (with a sequence constraint), enclosing a structure (with a minimum length
constraint),
\item or two consecutive structures.
\end{enumerate}

We recall the notion of a \emph{context-free grammar} here to show that simple secondary structures
allow a straightforward recursive description.}

\deffin{cfg}

\skript{Ignoring basepair sequence and distance constraints, in the RNA structure setting, the terminal
symbols are $T = \{\texttt{(}, \texttt{.}, \texttt{)}\}$ and $N = \{S\}$, where $S$ is also the start
symbol and represents a secondary structure. The productions are formalized versions of the above
rules, i.e.,
\begin{enumerate}\setcounter{enumi}{-1}
\item $S \to \varepsilon$, where $\varepsilon$ denotes the empty sequence,
\item $S \to \texttt{.}S$
\item $S \to S\texttt{.}$
\item $S \to \texttt{(}S\texttt{)}$
\item $S \to SS$
\end{enumerate}


Note that this context-free recursive description is only possible because we imposed the constraint
that basepairs do not cross.

Also note that this grammar is ambiguous: There are generally many ways to produce a given dot-bracket
string from the start symbol $S$. For the Nussinov Algorithm in the next section, this ambiguity is
not a problem. However, for other tasks, e.g.\ counting the number of possible structures, we need to
consider a grammar that produces each structure in a unique way. We can argue as follows: Either the
structure is empty, or it contains at least one base. In each nonempty RNA structure, look at the last
base. Either it is unpaired and preceded by a (shorter) prefix structure, or it is paired with some
base at a previous position. We obtain the following non-ambiguous grammar:
\[
    S \to \varepsilon \mid S\texttt{.} \mid S\texttt{(}S\texttt{)}
\]
where the vertical bar ($\mid$) denotes ``or'', i.e., it separates alternative right-hand sides of the
production.}





\section{The Nussinov Algorithm}\label{sec:the-nussinov-algorithm}
\komm{Example calculation for GGUCCA on page~\pageref{sec:nussinov-example}.}

\skript{To solve Problem~\ref{prob:prediction_rna}, we now give a dynamic programming algorithm based on the structural description
of simple secondary structures from the previous section. This algorithm is due to Nussinov and
Jacobson (1980). We also take into account the distance and sequence constraints for basepairs.


In the previous section, we have seen how to build longer secondary structures from shorter ones that
can be arbitrary substrings of the longer ones. As before, let
$s\in\{\mathtt{A}, \mathtt{C}, \mathtt{G}, \mathtt{U}\}^n$ be an RNA sequence of length $n$. For
$i\le j$, we define $M(i,j)$ as the solution to Problem~\ref{prob:prediction_rna} (i.e., maximally attainable score) for the
string $s[i\ldots j]$.

Since it is easy to find an optimal secondary structure of short sequences, let us start with those.
\begin{itemize}
    \item If $j-i\le\delta$ (in particular if $i=j$, and to avoid complications also if $i>j$), then
    $M(i,j) = 0$, since no basepair is possible due to the length or distance constraints (case 0).
    \item If $j-i>\delta$, then we can decompose the optimal structure according to one of the four cases.
    In each case, the resulting substructures must also be the optimal ones. Thus
    \begin{equation}\label{eq:nussinov}
        \glsB*{nussinov}
    \end{equation}
    where $\mu(i,j) := \mathrm{score}(\{s[i], s[j]\}) > 0$ if $\{s[i], s[j]\}$ is a valid basepair, and
    $\mu(i,j) := -\infty$ otherwise, excluding the possibility of any forbidden basepair $\{i,j\}$.
\end{itemize}


This recurrence states: To find an optimal structure for $s[i\ldots j]$, consider all possible
decompositions according to the grammar and their respective scores, and evaluate which score for
$s[i\ldots j]$ would result from each decomposition. Then pick the best one.

This is possible because the composing elements of the optimal structure are themselves optimal. The
proof is by contradiction: If they were not optimal and there existed better sub-structures, we could
build a better overall structure from them, which would contradict its optimality.

The above recurrence has still to be developed into an algorithm. In order to evaluate $M(i,j)$, we
need access to all entries $M(x,y)$ for which $[x,y]$ is a (strictly shorter) subinterval of $[i,j]$.
This suggests to compute matrix $M$ in order of increasing $j-i$ values. The initialization for
$j-i\le\delta$ is easily done. Then we proceed for increasing $d = j-i$, as in Algorithm~\ref{alg:nussinov}.}


\begin{algorithm}
    \caption{Nussinov Algorithm}
    \begin{algorithmic}[1]
        \Statex \textbf{Input:} RNA sequence $s = s[1 \dots n]$, scoring function for basepairs, minimum number $\delta$ of unpaired bases in a hairpin loop

        \Statex \textbf{Output:} Maximal score $M(i,j)$ for a simple secondary structure of each substring $s[i \dots j]$ and traceback indicators $T(i,j)$ indicating which case leads to the optimum

        \For{$i \gets 2$ to $n$}
            \State $M(i,i-1) \gets 0$
            \State $T(i,i-1) \gets \text{``init''}$ \Comment{$\epsilon$ (unpaired)}
        \EndFor

        \For{$d \gets 0$ to $\delta$}
            \For{$i \gets 1$ to $n-d$}
                \State $M(i,i+d) \gets 0$
                \State $T(i,i+d) \gets \text{``unpaired''}$
                \Comment{$.S$ and/or $S.$ (case 1 or 2)}
            \EndFor
        \EndFor

        \For{$d \gets \delta+1$ to $n-1$}
            \For{$i \gets 1$ to $n-d$}
                \State Compute $M(i,i+d)$ according to the recurrence
                \State Store the maximizing case in $T(i,i+d)$
                \Comment{cases 1--3; or case 4 with maximizing $k$}
            \EndFor
        \EndFor

        \State Report score $M(1,n)$
        \State Start traceback with $T(1,n)$
    \end{algorithmic}\label{alg:nussinov}
\end{algorithm}


\skript{To find an optimal secondary structure (in addition to the optimal score), we also store traceback
indicators in a second matrix $T$ that shows which of the production rules (and which value of $k$ for
the $S\to SS$ rule) was used at each step. By following the traceback pointers backwards, we can build
the dot-bracket representation of the secondary structure. For this, we start in cell $(1,n)$ and look
at the recursion of the algorithm: When we follow a $S\to SS$ production traceback, the process
branches recursively into the two substructures, reconstructing each substructure independently.
Diagonals mean $S\to\texttt{(}S\texttt{)}$ and horizontal or vertical movement means
$S\to S\texttt{.}\mid\texttt{.}S$. Note that when reaching the $\delta$-diagonals only horizontal and
vertical movement is allowed. Finally, when we end in the lowest diagonal (below the $i=j$ diagonal)
we have $S\to\varepsilon$.}


\paragraph{Analysis.}
\skript{The memory requirement for the whole procedure is obviously $O(n^2)$ and its time complexity is
$O(n^3)$.

There exists a faster algorithm using the Four-Russians speedup yielding an
$O\!\left(\frac{n^3}{\log n}\right)$ time algorithm (Frid and Gusfield, 2009), but this goes far beyond
the scope of these lecture notes.}

\skript{When reaching the $\delta$-diagonals we could move vertically or horizontally which is possible in the
ambiguous grammar. However, since in a hairpin loop a sequence of $S\to\texttt{.}S\mid S\texttt{.}$

    would lead to identical dot-bracket notations. Hence, we could also choose to allow \emph{only}

    backtracing of all optimal dot-bracket notations (only 1 backtrace instead of 4 for the dashed
    variant).}
