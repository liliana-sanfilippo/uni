Infos für beide:


Falling Ranking

r(z) = Σ rΣ(z[i]) · σq−i

Rising Ranking

r(z) = Σ rΣ(z[i]) · σi−1


Falling Ranking

Update-Idee: Bei falling wird links ein Zeichen entfernt und rechts ein neues angehängt:

r(ub) = (r(au) mod σq−1) · σ + rΣ(b)

Rising Ranking

Update-Idee: Bei rising wandert das neue Zeichen auf die höchste Stelle:

r(zb) = floor(r(au)/σ) + rΣ(b) · σq−1


Falling Unranking

r / σq−1 = c,   R   r'

Rising Unranking

r / σ = r',   R   c
